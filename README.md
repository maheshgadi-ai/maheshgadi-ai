# Hi, I'm Mahesh 👋

**AI engineer building agentic systems that are measured, safe, and observable.**

I build LLM applications end to end: multi-agent workflows, tool use and MCP, evaluation harnesses, and production guardrails. Every project ships with honest evals, tracing, tests, and Docker, because an agent you can't measure or inspect isn't ready for real users.

---

## 🤖 Agentic AI projects

| Project | What it does | Highlights |
|---|---|---|
| **[QuillvaneAI](https://github.com/maheshgadi-ai/QuillvaneAI)** | Multi-agent research assistant that plans, researches, writes, and critiques its own reports | Planner → researcher → writer → critic → editor loop · grounded citations · issue ledger against critic–editor oscillation · 12-question eval with adversarial cases · Streamlit app, MD/HTML/PDF export |
| **[TabulynxAI](https://github.com/maheshgadi-ai/TabulynxAI)** | Ask your database in plain English; the agent checks its own SQL against real results | Generate → execute → reflect · three independent safety layers (sqlglot validator, locked read-only engine, timeouts) · SQLite, DuckDB, PostgreSQL · reflection on/off evals |
| **[InboxternAI](https://github.com/maheshgadi-ai/InboxternAI)** | Email agent and MCP server that triages, drafts, and acts, with human-only approval before anything is sent | MCP server (Claude Desktop ready) · single-use approval tokens the model can't reach · lookalike-domain detection · append-only audit log · prompt-injection evals |

**Common to all three:** role-based model routing across OpenAI and Anthropic (default and budget profiles) · Langfuse tracing with per-run cost · layered architecture enforced by tests · CI on every push.
